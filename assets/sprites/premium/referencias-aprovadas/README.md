# Pranchas oficiais aprovadas — RiverStorm

Enviar aqui as oito pranchas PNG originais aprovadas pelo usuário.

Este diretório contém **pranchas de referência**, não sprites individuais prontos. Para uso no jogo, os quadros precisam ser recortados, ter transparência real verificada e ser mapeados à identidade correta de cada inimigo, aeronave, boss, cenário ou HUD.

Não usar as pranchas completas como sprites, nem substituir a identidade aprovada de personagens e bosses.
